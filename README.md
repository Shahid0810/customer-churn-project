# 📊 Customer Churn Prediction System

A Machine Learning web application that predicts whether a telecom customer is likely to **churn or stay** based on customer information, service usage, contract details, and billing information.

The project uses **Logistic Regression** for classification and **Streamlit** to provide an interactive web interface.

## 📌 Project Overview

Customer churn is an important business problem for telecom companies because losing customers can directly affect revenue.

This project uses historical customer data to build a machine learning classification model that predicts the probability of customer churn.

The application allows users to enter customer details and receive:

- Churn prediction
- Churn probability
- Stay probability
- Churn risk visualization

---

## 🎯 Problem Statement

Telecom companies need to identify customers who are likely to leave their services.

The objective of this project is to:

1. Analyze customer data.
2. Preprocess the dataset.
3. Explore important patterns using Exploratory Data Analysis (EDA).
4. Train a Logistic Regression classification model.
5. Evaluate the model using classification metrics.
6. Deploy the model as an interactive Streamlit application.
